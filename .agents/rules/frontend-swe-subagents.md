## 1. Squad Roles & Boundaries

```
[Frontend Lead / Orchestrator]
       │
       ├──► [API Contract & Integration Sub-Agent]  (swagger.json, generate-api, httpResource)
       ├──► [Core State & Signals Sub-Agent]        (Smart Containers, Signals, Routing, Guards)
       ├──► [Material UI & UX Sub-Agent]            (Presentational Components, Tables, Dialogs)
       │
       └──► [Independent Code Critic & QA Sub-Agent] (OnPush audit, diff checks, npm test, build)
```

### Role Specifications
1. **Frontend Lead / Orchestrator**: Manages feature lifecycle, performs adversarial grilling per AGENTS.md §2.1, decomposes into `[SEQUENTIAL]` vs `[PARALLEL]` tasks, manages synchronization barriers.
2. **API Contract Sub-Agent**: Monitors `src/swagger.json`, runs `npm run generate-api`. **Never manually edits `src/api/`** (AGENTS.md §2.13 Never Do). Creates typed services wrapping generated API functions.
3. **Core State Sub-Agent**: Implements Smart containers and routing. Uses Angular 19+ Signals (per `angular-signals-onpush.md`). Guarantees zoneless immutability.
4. **Material UI Sub-Agent**: Implements Dumb presentational components. Input via `input()`, output via `output()`. Monochrome theme, 8px grid, 44×44px touch targets. Uses `@defer (on viewport)` for below-fold heavy elements. **Never uses `!important`**.
5. **Code Critic & Security Auditor**: Isolated read-only context. Audits against the 4 pillars (AGENTS.md §1, Role 5). Issues binary `APPROVED` / `CHANGES_REQUESTED` with drop-in diffs.
6. **SWE Learn & Meta-Agent**: Researches patterns, audits rules, prunes knowledge memory per AGENTS.md §4.

## 2. Angular-Specific Boundary Extensions

> Inherits the universal **Always / Ask / Never** model from [AGENTS.md §2.13](../AGENTS.md).
> Below are **Angular-specific additions only**.

**Ask First (Angular-specific):**
- Modifying `angular.json` (build targets, budgets, assets).
- Changing `tsconfig.json` or `tsconfig.app.json` compiler options.
- Modifying environment files (`src/environments/environment*.ts`).
- Changes to routing guards, interceptors, or authentication flows.

**Never Do (Angular-specific):**
- Manually edit files in `src/api/` (autogenerated by `ng-openapi-gen`).
- Use `!important` in component styles.
- Bypass Angular `DomSanitizer` without explicit human approval.
