# OpenAPI & Contract Synchronization Knowledge Memory

Curated lookup of verified gotchas, anti-patterns, and proven fixes for autogenerated API clients (`ng-openapi-gen`) and backend contract synchronization.

---

### 1. Manual Edits in `src/api/` Overwritten on Regeneration
- **Symptom**: Custom helper methods, comments, or modified type annotations inside `src/api/` disappear unexpectedly after running `npm run generate-api`.
- **Root Cause**: `src/api/` is a pure build artifact generated directly from `src/swagger.json`.
- **Proven Fix**:
  ```diff
  // WRONG: Editing src/api/models/customer.ts directly
  
  // CORRECT: Create domain wrapper or extension in src/app/
  + // In src/app/core/models/customer-ui.model.ts
  + import { CustomerDto } from '../../../api/models';
  + export interface CustomerUiModel extends CustomerDto {
  +   isExpanded?: boolean;
  + }
  ```

---

### 2. Deep Import Paths Causing Tree-Shaking & Refactoring Breakages
- **Symptom**: Imports break when `ng-openapi-gen` regenerates files, or multiple copies of model definitions enter bundle chunks.
- **Root Cause**: Importing directly from internal files (`src/api/models/customer-dto.ts` or `src/api/fn/...`) instead of using barrel index files.
- **Proven Fix**:
  ```diff
  // WRONG: Deep relative imports into generated subfolders
  - import { CustomerDto } from '../../api/models/customer-dto';
  - import { customersGetAll } from '../../api/fn/customers/customers-get-all';

  // CORRECT: Import strictly from barrel files
  + import { CustomerDto } from '../../api/models';
  + import { CustomerService } from '../../api/services';
  ```

---

### 3. Missing Contract Synchronization Barrier
- **Symptom**: Angular build fails with `Property 'xyz' does not exist on type 'CustomerDto'` after backend changes are pulled.
- **Root Cause**: Backend DTO changed in `Finance.ServerApi`, but `src/swagger.json` and `src/api/` were not updated before the frontend build started.
- **Proven Fix**:
  ```bash
  # Step 1: Copy updated swagger.json from backend build
  # Step 2: Regenerate Angular client before running build/serve
  npm run generate-api
  npm run build
  ```

---

### 4. Date-Time Strings vs Date Objects in Generated Models
- **Symptom**: Calling `.getFullYear()` or date formatting functions on an autogenerated DTO throws `TypeError: c.createdAt.getFullYear is not a function`.
- **Root Cause**: JSON serialization produces ISO 8601 strings (`string`), not JavaScript `Date` instances.
- **Proven Fix**:
  ```diff
  // WRONG: Assuming generated date field is a Date object
  - const year = customer.createdAt.getFullYear();

  // CORRECT: Parse ISO string or use DatePipe in template
  + const year = new Date(customer.createdAt).getFullYear();
  // Template: {{ customer.createdAt | date:'mediumDate' }}
  ```
